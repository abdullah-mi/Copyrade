# Product media capture guide

No product screenshot or demo is currently checked into this directory. Do not
substitute a mockup and describe it as the working application.

Before the public alpha, capture one real, restrained visual for the root
README:

1. Use synthetic clipboard text with no account, email, device, token, or room
   code visible.
2. Show the mobile web app connected to the Windows receiver.
3. Show a successful send followed by `Ctrl+V` into a plain Windows editor.
4. Crop or blur unrelated browser and desktop information.
5. Prefer a side-by-side PNG or a short compressed WebM with readable light and
   dark GitHub backgrounds.
6. Add descriptive alt text and record the tested app commit in the pull
   request that adds the asset.
